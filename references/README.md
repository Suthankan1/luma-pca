# Design and research reference assets

`legacy-frontend-demo/` is the previous **standalone HTML + JavaScript demo** with fictional data, not the production Next.js application and not a secure authorization implementation. It is bundled so coding agents can inspect screen layouts, responsive behaviors, navigation, attendance graphs, and visual identity while porting features one at a time.

Never deploy the legacy demo as the official academy system or claim its simulated Zoom data is real. The source architecture and research are under `docs/architecture` and `docs/research`.
