# Definition of Done

A feature is DONE only if all apply: acceptance criteria fulfilled; tests executed and green, including negative/error cases and role/scope restrictions; no secrets or student PII committed/logged; API contract/error behavior updated; database migration reviewed and forward-compatible; documentation and agent checkpoint updated; monitoring/audit events handled where applicable; `git diff --check` clean; developer can explain rollback/failure mode. Do not call an architectural proposal 'implemented'. Zoom features require real licensed sandbox proof before release.
