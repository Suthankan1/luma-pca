# Backend-specific agent instructions
Read `../AGENTS.md` and `../docs/security/JWT-AUTH.md` first. Use Java 21, Spring Boot 4.1.2 and one modular monolith. Only expose `system/status` and health on the scaffold; all other routes deny by default. Never implement real JWT signing using hard-coded or symmetric placeholder keys. Any auth slice must include lockout/rate-limit, password-hash, refresh rotation, authorization and cross-batch tests. Attendance belongs to `(class_session_id, student_id)`; calculations merge/clamp connection intervals. Preserve raw signed webhook receipt and reconciliation boundaries.
